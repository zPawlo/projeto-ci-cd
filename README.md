# Projeto CI/CD - Lista de Tarefas

Projeto simples em React + Vite criado para a atividade de DevOps e CI/CD.

## Como executar

```bash
npm install
npm run dev
```

Depois, abra o endereço mostrado pelo Vite no navegador.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
